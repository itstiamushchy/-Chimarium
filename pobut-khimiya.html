Їжа, напої та консервація
Алкоголь · Кулінарія · М'ясне виробництво · Бджільництво · Молекулярна кухня
1.1 Алкоголь, дистиляція та виноробство
Розведення та купажування: розрахунок води для розведення спирту/самогону з урахуванням контракції; змішування дистилятів різної міцності; розведення настоянок цукровим сиропом
🔢 калькулятор
Корекція вимірювань: поправка показань спиртоміра за температурою; перерахунок оптичного та цифрового рефрактометра (Brix, цукор, T-корекція)
📐 формула
Фракційна перегонка: розрахунок об'єму «голів» (3–10% від АС); вихід «тіла» та «хвостів»; обчислення абсолютного спирту у сирці
🔢 калькулятор
Брага та ферментація: гідромодуль (цукор:вода); потенційна міцність за щільністю; дозування дріжджів; перерахунок Brix / Plato / SG / g/l; праймінг пива/сидру
🔢 калькулятор
Виноробство: шапталізація (підвищення міцності); зниження кислотності (вода, мармур, крейда); дозування піросульфіту калію для стерилізації
📐 формула
1.2 Кулінарія, випічка та кондитерська справа
Оцтовий калькулятор: 70% есенція → 3/5/6/9% столовий оцет; взаємозаміна 6% і 9%; перерахунок бальзамічного, яблучного, винного оцту
🔢 калькулятор
Соління, маринади та розсоли: концентрація солі (% або g/l) для квашення і консервації; сухе соління (% від маси сировини); розрахунок цукру, оцту та спецій на об'єм банок
🔢 калькулятор
Кондитерська справа: таблиця проб цукрового сиропу за T°C; конвертер желюючих агентів (желатин Bloom, агар-агар, пектин); розрахунок інвертного сиропу
📊 таблиця
Випічка: погашення соди (сода + лимонна кислота/оцет); Baker's Percentages — вологість, сіль, дріжджі від маси борошна
🔢 калькулятор
1.3 М'ясне виробництво (ковбаси, шинки, джерки)
Нітритна сіль: розрахунок NaNO₂ (0,5–0,6%) у суміші зі звичайною сіллю для безпечного дозрівання
⚠️ точний розрахунок
Вологовтрата при в'яленні (усушка) м'яса та сиру; дозування фосфатів та стартових культур; шприцювання (% розсолу від маси сировини); таблиця зв'язування води у м'ясних емульсіях
📊 таблиця
1.4 Плодово-ягідна переробка, сушіння та бджільництво
Дегідратація: коефіцієнт усушки для фруктів, овочів, грибів, пастили; таблиця залишкової вологості сухофруктів для тривалого зберігання
📊 таблиця
Соки: вихід соку з різної сировини (% від маси); дозування пектинази для освітлення та збільшення виходу
📐 формула
Бджільництво: цукрові сиропи (1:1, 1.5:1, 2:1) для підгодівлі; розрахунок канді та препаратів; спиртові та масляні настоянки прополісу (10%, 20%, 30%); воскові свічки та захисні мастики
🔢 калькулятор
1.5 Молекулярна кулінарія вдома
Сферифікація: точний розрахунок альгінату натрію (0,5–1%) та лактату/хлориду кальцію для прямої та зворотної сферифікації
🔢 калькулятор
Стабілізація соусів: дозування ксантанової камеді для загущення без нагрівання
📐 формула
🚧

Сад, город, природа та тваринництво
Агрохімія · Басейни · Акваріум · Грибництво · Птахівництво · Насіння
2.1 Агрохімія: сад і город
Перерахунок дозувань отрутохімікатів (g/га, kg/га → грами на 10 л ранцевого обприскувача); концентрація робочого розчину (% або ml/l)
🔢 калькулятор
Бордоська рідина: мідний купорос + негашене вапно → нейтральний 1% розчин; Бургундська рідина: мідний купорос + кальцинована сода
📐 формула
Сумісність у бакових сумішах (інсектициди, фунгіциди, добрива); розрахунок NPK з мінеральних солей; підкислення ґрунту (сірка, алюмінієві квасці — під гортензії, лохину, рododendrons)
📊 таблиця
Калькулятор EC/TDS та солоності поживного розчину для гідропоніки та крапельного поливу
🔢 калькулятор
2.2 Басейни та штучні водойми
Шокове хлорування (гранули хлору на m³); регулювання pH (pH-мінус та pH-плюс для рівня 7,2–7,6); дозування альгіцидів та флокулянтів; сіль для хлоргенератора
🔢 калькулятор
2.3 Акваріумістика
Карбонатна та загальна твердість (KH, GH); змішування водопровідної та осмосованої води; дозування Макро (N, P, K) та Мікро (Fe) добрив у PPM; безпечна доза сайдексу проти чорної бороди
🔢 калькулятор
2.4 Грибництво, компостування та біогумус
Вологість субстрату (солома, тирса, шелуха) для гливи та печериць; pH-коригування гіпсом, крейдою, вапном; норма внесення міцелію (% від маси субстрату)
🔢 калькулятор
Співвідношення C:N для прискореного компостування; норма доломітового борошна/попелу для розкислення купи
📐 формула
2.5 Птахівництво, тваринництво та кормоприготування
Втрата маси яєць під час інкубації (% вологості по вікам); дезінфекція інкубаторів (марганцівка, пероксид); протеїновий та енергетичний баланс комбікорму (матриця Пірсона)
📊 таблиця
Дозування підкислювачів води (лимонна, яблучна, ортофосфорна кислота); розрахунок внесення преміксів та вітамінів на об'єм води/корму
🔢 калькулятор
2.6 Зберігання та обробка насіннєвого матеріалу
Дозування стимуляторів росту та протруйників (KMnO₄, H₂O₂, бурштинова кислота); сольові розчини для калібрування насіння методом спливання
📐 формула

Прибирання, дезінфекція та догляд за будинком
Антисептики · Побутова хімія · Миловаріння · СПА вдома
3.1 Дезінфекція та антисептики
70% спиртовий антисептик з 96% етанолу або 99% ізопропанолу (з гліцерином та перекисом)
🔢 калькулятор
Розведення «Білизни» та хлорвмісних препаратів: розрахунок PPM активного хлору для обробки поверхонь
🔢 калькулятор
Розведення перекису водню з 30–35% (пергідроль) до 3% побутового
📐 формула
3.2 Побутова хімія та видалення нальоту
Лимонна або щавлева кислота для видалення вапняного нальоту та іржі; нейтралізація пролитих агресивних засобів (кислота ↔ луг)
📐 формула
Засоби для миття вікон (нашатирний спирт + ізопропанол); поліролі для меблів (восково-скипидарні та силіконові емульсії)
🔢 калькулятор
Розкоксовуючі та знежирювальні розчини (ізопропанол, NaOH, ПАР); ферментні суміші проти органічних запахів (сеча, сирість, гар); сода+оцет для пластику та холодильника
📐 формула
3.3 Миловаріння (Soap Calculator)
Розрахунок маси лугу (NaOH для твердого, KOH для рідкого мила) на основі числа омилення олій; розрахунок % пережиру (Superfat); об'єм води для розчинення лугу
🔢 калькулятор
3.4 СПА вдома — мийні та купальні засоби
Бомбочки для ванни: сода + лимонна кислота (1:2) для повної нейтралізації; масляна фаза + твін-80 для розчинення олій без плівки
🔢 калькулятор
Пральний гель: мильна стружка + кальцинована сода + бура (безфосфатний)
📐 формула

Домашня косметика, гігієна та фітотерапія
Гігієнічні засоби · Трав'яні препарати · Мило та шампуні · Доглядова косметика
4.1 Профілактичні та гігієнічні засоби
Водні настої трав (ромашка, шавлія, календула, м'ята) для полоскання та обробки шкіри; парові інгаляції з ефірними оліями (1–2 краплі на об'єм)
📐 формула
Ізотонічний (0,9%) та гіпертонічний (2–3%) сольові розчини для гігієни носоглотки; содово-сольовий розчин з йодом для полоскання ротової порожнини
🔢 калькулятор
4.2 Компреси та зовнішні засоби
Спиртові настоянки прополісу або трав для зовнішнього розтирання суглобів; масляні витяжки (мацерати) зі звіробою, календули, обліпихи
📐 формула
4.3 Мило, шампуні та доглядова косметика
Олійно-лужний баланс (число омилення) для твердого (NaOH) та рідкого (KOH) мила — гарячий і холодний способи; тверді шампуні на основі кокосульфату, кокоїл ізетіонату
🔢 калькулятор
Масляна та водна фаза для живильних кремів; вибір натуральних емульгаторів (бджолиний віск, олівацій, цетиловий спирт); захисні бальзами для губ та рук (баттери + рідкі олії)
📐 формула
Бомбочки для ванни: сода + лимонна кислота + наповнювач (2:1:1); скраби для тіла (цукор, сіль, кавова гуща + олії)
🔢 калькулятор

Майстерня, будівництво та ремонт
Автохімія · Смоли · Будрозчини · Деревина · Шкіра
5.1 Автохімія
Антифриз: розведення концентрату пропіленгліколю/антифризу водою під бажану T замерзання; концентрат омивача скла (літній і зимовий)
🔢 калькулятор
Промивання радіатора (лимонна кислота або трилон Б); електроліт для акумулятора (H₂SO₄ + дистильована вода, густин 1,28 г/см³); силіконові відновники для гумових ущільнювачів
📐 формула
5.2 Епоксидні, поліефірні смоли та силікони
Точний розрахунок пропорцій смола:затверджувач; додавання пластифікатора (ДБФ) та прискорювача; об'єм смоли для заливки форм і стільниць
🔢 калькулятор
Двокомпонентні силікони (олов'яний та платиновий каталізатор) для гнучких форм; силіконове масло (ПМС) для пом'якшення та текучості
📐 формула
5.3 Будівництво та саморобні розчини
Цементно-піщані суміші (М400, М500); водоцементне співвідношення (В/Ц) для міцності бетону; рідке скло, пластифікатори та протиморозні добавки
🔢 калькулятор
Ґрунтовки глибокого проникнення з концентратів; розведення фарб, лаків та емалей розчинниками (646, уайт-спірит, ксилол, ацетон) для краскопульта або пензля
📐 формула
5.4 Захист та обробка деревини
Масляно-воскові суміші (лляна олія + бджолиний віск + скипидар); моріння залізним купоросом або чаєм/кавою; захист від гниття (фтористий натрій, мідний купорос)
📐 формула
5.5 Виделка, дублення та догляд за шкірою
Пікель (оцтова/сірчана кислота + сіль) для обробки шкур; жирові емульсії для пом'якшення; рослинне та хромове дублення (таніни або хромові квасці)
📐 формула

Металообробка, ювелірна справа та ремесла
Травлення · Гальваніка · Патинування · Пайка · Кераміка
6.1 Травлення металів
Хлорне залізо (FeCl₃): потрібна густин розчину для травлення міді/латуні; саморобна суміш: H₂O₂ + лимонна кислота + сіль
🔢 калькулятор
6.2 Патинування, воронування та чорніння
Чорніння сталі: сірчана печінка, сполуки амонію, кислоти; патинування міді та бронзи (мідний купорос + аміак)
📐 формула
6.3 Пайка та флюси
Каніфольно-спиртові флюси (ФКЕ): каніфоль + ізопропанол; травлена кислота для пайки (цинк + HCl); відбіли для зняття флюсу; ультразвукові ванни (нашатир + мило)
📐 формула
6.4 Домашня гальваніка та гальванопластика
Склад електроліту (мідний купорос + H₂SO₄); щільність струму на площу (А/дм²); захисні лаки для маскування; графітизація неметалевих предметів
🔢 калькулятор
6.5 Кераміка, гончарство та ливарництво
Вологість та густина глазурного шлікеру; дефлокулянти (рідке скло, сода); рецепти глазурей; усадка глини/гіпсу; пропорції гіпс:вода для ливарних форм
📐 формула

Художні матеріали, фарби та покриття
Художні фарби · Будівельні покриття · Антикорозійні склади · Антипірени · Текстиль
7.1 Художні фарби та графічні матеріали
Перетирання сухих пігментів з лляною/горіховою олією для олійних фарб; яєчна емульсія (жовток + оцет/вода) для темпери; гуміарабік + гліцерин + мед для акварелі та гуаші
📐 формула
Пасть: зв'язуюче (трагакант, гуміарабік, КМЦ) + пігмент + крейда; природні смоли (даммара, каніфоль, шелак) у скипидарі або спирті для лаків
📐 формула
7.2 Будівельні та фасадні фарби
Вапняна фарба (гашене вапно + сіль + оліфа); силікатна фарба (рідке скло + мінеральні пігменти); казеїновий клей і фарба (сир + вапно або нашатир)
📐 формула
Шведська та Фінська фарби: борошно + залізний/мідний купорос + сіль + сурик/охра + лляна олія (термін служби 15–20 років для деревини)
📐 формула
7.3 Антикорозійні та термостійкі покриття
Графітове покриття (графіт + оліфа/епоксидна смола) для захисту металу; термостійке покриття (КО-85 + алюмінієва пудра «серебрянка», витримує 400–600°C)
📐 формула
7.4 Протигрибкові та вогнетривкі суміші
Антисептики для деревини (мідний/залізний купорос, фтористий натрій, бура); ЧАС-містні глибокопроникаючі протигрибкові розчини
📐 формула
Вогнебіозахист деревини: бура (Na₂B₄O₇) + борна кислота (H₃BO₃) у співвідношенні 1:1 або 3:5; фосфат та сульфат амонію; обмазки для печей (глина + шамот + рідке скло)
🔢 калькулятор
7.5 Текстиль: фарбування та догляд за одягом
Кількість барвників від маси сухої тканини; фіксатори: сіль (бавовна, льон) або оцет (вовна, шовк); вибілювання (гідросульфіт натрію або перекис)
🔢 калькулятор
Виводники плям (нашатир, ацетон, щавлева кислота, гліцерин); визначення pH для безпечного прання різних типів волокон

Реставрація, папір, скло та природні клеї
Реставрація · Паперотворення · Склярна справа · Природні клеї · Шовківництво
8.1 Реставрація та музейна справа
Трилон Б (5–10%) для м'якого очищення мідних та бронзових монет без пошкодження; мильні та спиртово-бензинові ванни для знежирення антикваріату
📐 формула
8.2 Саморобне паперотворення
Пульпа: сухе волокно (макулатура, бавовна, льон) до води для заданої щільності; NaOH або кальцинована сода для розварювання грубих рослинних волокон
📐 формула
Проклеювання: желатин, крохмаль, каніфольне мило, квасці — щоб чорнило не розпливалося; мінеральні наповнювачі (крейда, каолін) для білизни та гладкості
📐 формула
Мармуровий папір (Ебру): карагінан або КМЦ як основа + бичача жовч у фарбах; вощанка: бджолиний віск + лляна олія + каніфоль; нейтралізація кислотності старих книг (Ca/Mg гідрокарбонат)
📐 формула
8.3 Обробка скла (склярна справа)
Матирування скла: пасти та розчини на основі фториду амонію (безпечна альтернатива плавиковій кислоті); ЗОР для різання та свердління (гас + скипидар + олія)
⚠️ обережно
Полірування скла та оптичних лінз: суспензія оксиду церію або крокусу (оксид заліза) для видалення подряпин
📐 формула
8.4 Природні клеї, смоли та герметики
Кістковий/міздровий столярний клей (60°C, відновлення та пропорції з водою); борошняний і крохмальний клейстер з мідним купоросом (антипліснявний); казеїновий клей для деревини
📐 формула
Сосновий вар для конопачення (смола + каніфоль + зола + олія); замазки для скла, печей та кераміки (оліфа, крейда, гліцерин, гліт)
📐 формула
8.5 Шовківництво та натуральні волокна
Дегумування коконів: кальцинована сода або мило для виварювання та видалення серицину; кислотні розчини для пом'якшення грубих волокон (льон, коноплі, кропива)

🔢 калькулятор

🔢 калькулятор
